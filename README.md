# ⚔️ Clash of baNG - Game Community Platform

> A highly interactive, user-centric community website designed for gamers, developed as a Human-Computer Interaction (HCI) academic project.

## 🔗 Live Demo
[View Live Demo Here](https://adistyasavira.github.io/clash-of-bang/) 

## 📖 About The Project
**Clash of baNG** is a front-end web application built entirely with native web technologies. It focuses heavily on **Human-Computer Interaction (HCI)** principles, ensuring an intuitive user experience, seamless navigation, and an immersive aesthetic tailored specifically for a gaming community. 

Rather than relying on heavy frameworks, this project demonstrates a strong foundational understanding of DOM manipulation, semantic structure, and CSS layout management.

## ✨ Key Features
* **User Authentication Flow:** Intuitive and accessible UI for user registration and login (`register.html`, `profile.html`).
* **Interactive Lore & Profiles:** Detailed pages for characters (troops) and game lore with engaging visual layouts.
* **HCI-Driven Design:** Consistent visual hierarchy, clear feedback loops, and intuitive navigation structures.
* **Zero-Dependency:** Built completely from scratch without external CSS or UI libraries.

## 🛠️ Tech Stack
* **HTML5:** Semantic structuring and accessibility.
* **CSS3:** Custom styling, animations, and responsive layouts.
* **Vanilla JavaScript:** DOM manipulation and interactive UI components.
